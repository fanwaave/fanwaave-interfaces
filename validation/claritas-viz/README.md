# Claritas Viz boundary

Tracking: DEN-617.

Fanwaave visualization surfaces use `claritas-viz` through this runtime-neutral interface contract. The interface layer contains no rendering function bodies; it only admits provider, purpose, capability, and runtime vocabulary.

TypeSpec and Draft 2020-12 JSON Schema are independent peer authorities. TJSV generates comparison evidence from TypeSpec and fails closed when the authorities or recorded fixtures disagree.
